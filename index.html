03

Get started

Two lines from silent to alive.

1. Install the package
$ npm install sonicflow
2. Mark up and bind
<!-- one attribute per behavior -->
<button data-sf-press data-sf-release>Save</button>
<a data-sf-hover="tick">Docs</a>
<button data-sf-toggle>Dark mode</button>
import { bind, play, setVolume } from 'sonicflow';
bind();                  // wires every data-sf-* attribute
setVolume(0.7);           // global loudness, from 0 to 1
play("success");         // inherits the global volume
play("success", { volume: 0.4 }); // quieter for this play only
