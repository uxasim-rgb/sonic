        $npm install sonic-flow
        $yarn add sonic-flow
        $pnpm add sonic-flow 
        <!-- No build step: load it as an ES module -->
<script type="module">
  import { bind } from "https://unpkg.com/sonic-flow";
  bind();

      2. Tag your elements

        Add data-sf-* to anything interactive and call bind() once after the page loads.

      3. Or play on demand

        Call play("name") from any handler. Names are exactly what you see in the library above.

      <!-- Tag any element with a behavior -->
<button data-sf-press data-sf-release>Save</button>
<a href="/docs" data-sf-hover="hover-soft">Docs</a>
<input type="checkbox" data-sf-toggle>
<button data-sf="success">Publish</button>

      API

      Five functions and a handful of attributes. That’s the whole surface.

      Functions

      • play(name, options?)

        Plays a sound by name. Pass { volume } (0 to 1) to override the master volume for that call.

      • bind(options?)

        Wires every data-sf-* element on the page. Call it once when the DOM is ready. { volume } also sets the master volume.

      • setVolume(value)

        Sets the master volume, from 0 to 1. The default is 0.7.

      • setPitch(semitones)

        Shifts every sound up or down. 0 is the original pitch.

      • getSounds()

        Returns an array with the name of every sound.

      Attributes

      AttributePlays onDefault sound
      data-sf-hoverPointer enterhover
      data-sf-pressMouse down, touch startpress
      data-sf-releaseMouse up, touch endrelease
      data-sf-toggleClick, alternatingtoggle-on / toggle-off
      data-sf-focusFocusfocus
      data-sf-blurBlurblur
      data-sf="name"ClickThe named sound

      Hover, press and release take a sound name as their value, for example data-sf-hover="hover-soft".

      Sounds stay silent for visitors who have prefers-reduced-motion turned on. Loaded from a CDN, the same functions are on window.SonicFlow.
