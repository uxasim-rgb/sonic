How it works

Add an attribute. That's it.

Put data-sf-* on any element, call bind() once on page load. Try these — they're wired up right here.

data-sf-press

A click sound when the user taps. Good for likes, reactions, confirms.

data-sf-toggle

Different tone for on vs off. Works on any checkbox or switch.

data-sf-press + release

Mouse-down and mouse-up as a pair. Feels like a real button.

Why this exists

Sound makes interfaces feel real.

Click a card. You'll hear what it does.

Get started

Two steps. You're done.

1. Add Sonic

$
<!-- paste before </body> --> <script src="https://unpkg.com/sonic-flow@latest"></script> <script>SonicFlow.bind();</script>

No build step needed with the script tag. Drop it in any HTML page.

2. Wire up your elements

Add data-sf-* attributes to buttons, links, inputs — then call bind() when the page loads.
